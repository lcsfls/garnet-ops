# Map data

`world-map.ts` is generated by `scripts/build-world-map.mjs` from **Natural Earth** 1:110m
admin-0 country boundaries, which are in the **public domain** (https://www.naturalearthdata.com/about/terms-of-use/),
as packaged by **world-atlas 2.0.2** (ISC licence, Copyright 2013-2019 Michael Bostock;
https://github.com/topojson/world-atlas). The shapes are projected (Natural Earth projection) and
stored as SVG path data. Nothing is loaded from a map server at run time.

Natural Earth does not require attribution; we give it anyway (README, `docs/COMPONENTS.md`).
Borders on this map are those of Natural Earth's generalised 110m data and imply no political position.

`world-geo.ts` is generated by the same script from the same data: the shapes as longitude and latitude
geometry (a TopoJSON subset) for the globe view, which draws them with d3-geo (ISC). It also holds the centroid of
each country's largest part, where the globe starts the arcs of its source addresses. Still nothing is loaded at
run time except this file, as a separate chunk when the globe opens.
