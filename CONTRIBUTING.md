# Contributing

Thank you for your interest in GarnetOps.

## Before you open a pull request

GarnetOps is dual-licensed (AGPL-3.0-only and a commercial license, see
[`LICENSING.md`](LICENSING.md)). To keep that possible, every contribution
needs a **Contributor License Agreement (CLA)** that lets IT Systeme Flores UG
license the contribution under both licenses. The CLA is being prepared; **until
it is published, pull requests from outside contributors cannot be merged.**
Issues, bug reports and ideas are welcome right away.

Security issues: see [`SECURITY.md`](SECURITY.md), never a public issue.

## How we work

- Read [`AGENTS.md`](AGENTS.md): it is the rulebook for every contributor,
  human or AI agent. Security first, never break user space, clean licensing
  of every dependency, English only in the repository.
- Small, focused changes; Conventional Commits; tests for what you change;
  `corepack pnpm lint`, `typecheck`, `test` and the end-to-end tests green.
