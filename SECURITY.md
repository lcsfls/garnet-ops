# Security policy

Security comes first in GarnetOps (see `AGENTS.md`). Thank you for helping.

## Reporting a vulnerability

Please **do not open a public issue** for a vulnerability. Report it
privately through GitHub's "Report a vulnerability" button
(Security → Advisories) in this repository.

Include what you found, how to reproduce it, the affected version or commit,
and the impact you expect. We confirm receipt within 3 working days, keep you
informed, and credit you in the advisory unless you prefer otherwise.

## Supported versions

GarnetOps has not had its first release yet. Until then, only the latest
commit on `main` receives fixes. After the first release, security fixes are
free of charge for every supported version line, independent of any
maintenance contract.
